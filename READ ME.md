# Trabajo Práctico Final - Migración a React (PF.A)

Proyecto desarrollado para el Curso Inicial Front-End de la Universidad Tecnológica Nacional (UTN).

## Características del Proyecto
- Estructura limpia migrada a componentes modulares utilizando **Vite** y **React.js**.
- Enrutamiento dinámico de secciones mediante **React Router v6**.
- Componentización estructurada: `Navbar`, `Layout`, `Cards`, `Gallery`, `Contact` y `Footer`.
- Formulario de contacto controlado mediante el hook `useState` con captura de eventos, método preventDefault y reinicio de estado.

## Requisitos de Ejecución

1. Clonar o descargar el repositorio.
2. Abrir la terminal en la carpeta raíz del proyecto.
3. Ejecutar el siguiente comando para instalar las dependencias necesarias:
   ```bash
   npm install
   ```
4. Iniciar el servidor de desarrollo local mediante:
   ```bash
   npm run dev
   ```
5. Abrir la dirección URL provista por la consola (habitualmente http://localhost:5173/).
